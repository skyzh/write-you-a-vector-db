# Your Workspace Rules

Implement the exercises only in this directory unless the course page says
otherwise.

- Do not inspect `../../vector-db/core`, `../../vector-db/datafusion`, Git history,
  remote branches, or published solutions.
- You may read the Rust course pages and edit `../datafusion`
  during Day 1.
- Do not change public APIs or tests to make an implementation pass.
- Preserve deterministic tie-breaking and the validation behavior described by
  each day.
- Run the checkpoint's focused tests, then `cargo x test-day N` and
  `cargo x test-through N`, before continuing to the next day.
