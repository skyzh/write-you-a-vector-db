# Vector DataFusion Starter

In Chapter 1, you will use this crate to build an Arrow table, a custom physical
scan, and safe vector sort pushdown. Its SQLLogicTests establish the optimizer
boundary that IVFFlat, NSW, HNSW, and IVF-PQ use unchanged through Chapter 5.

The crate includes the execution helpers you need, so you can focus on the
explicit Chapter 1 TODOs in the guide.
