# Vector Core Starter

In the first two Rust chapters, you will use this crate to:

1. validate the in-memory dataset used by the DataFusion table;
2. implement recall measurement and IVFFlat.
Start with the existing metric math, deterministic `FlatIndex`, and top-k
helpers. Your work is dataset validation, recall measurement, and IVFFlat. Run
commands from the parent `rust/` workspace.
