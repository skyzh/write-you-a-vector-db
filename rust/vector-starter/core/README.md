# Vector Core Starter

In the four Rust chapters, you will use this crate to:

1. validate the in-memory dataset used by the DataFusion table;
2. implement recall measurement and IVFFlat; and
3. build and search a bounded-degree NSW graph; and
4. add seeded hierarchy with HNSW.
Start with the existing metric math, deterministic `FlatIndex`, and top-k
helpers. Run commands from the parent `rust/` workspace.
